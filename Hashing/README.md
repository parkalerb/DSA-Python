# 💻 Problems Solved

## 1️⃣ Two Sum

### Problem Statement

Given an array of integers and a target value, return the indices of the two numbers whose sum equals the target.

### Concepts Used

- Dictionary
- HashMap
- One-pass traversal
- Optimized lookup

**Time Complexity:** `O(n)`

**Space Complexity:** `O(n)`

---

## 2️⃣ Valid Anagram

### Problem Statement

Determine whether two strings are anagrams of each other.

### Concepts Used

- Dictionary
- Character Frequency Counting
- String Traversal

**Time Complexity:** `O(n)`

**Space Complexity:** `O(n)`

## 3️⃣ First Unique Character in a String
